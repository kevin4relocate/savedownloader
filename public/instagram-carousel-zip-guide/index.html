Instagram carousel ZIP on iPhone and Android: how it works

A carousel can contain photos, videos, or both. Saving several items in one ZIP is convenient, but mobile browsers have different download flows and limited memory. This guide explains the actual SaveDownloader behavior, including when to save items one by one.

Published September 27, 2026. Save only media you are authorized to download and respect source-platform rules.

Before you start: check the original post

Open the original public post in your browser and confirm you have permission to download it. Copy the post's share link, not the temporary media address. A public post can still be subject to creator rights and platform restrictions. Our responsible downloads guide explains those distinctions.

What Download all (.zip) actually does

  1. Open the Instagram Downloader and paste a supported public post URL.
  2. Select Get media. The result shows the media items that SaveDownloader was able to identify. If the result contains two or more items, Download all (.zip) becomes available.
  3. When you choose the ZIP option, your browser requests each available item and builds a single archive locally. SaveDownloader does not create a permanent online ZIP library.
  4. Keep the page open until ZIP preparation finishes. If one item cannot be retrieved, the archive cannot be completed. Try downloading the available items individually instead.

Saving a ZIP on iPhone Safari

After the ZIP is prepared, Safari users see a separate Save file action. Tap it rather than closing the page when preparation completes. Check Safari's Downloads control and, if needed, the Downloads folder in the Files app. Your default download location may be iCloud Drive or On My iPhone depending on your device settings.

If you only see a preview or nothing appears in Files, review Safari's download location and try the explicit Save file control again. An on-screen “ready” message means the archive was prepared; it does not independently confirm that iOS stored the file.

Saving a ZIP on Android Chrome

Chrome usually handles the generated ZIP as a browser download after preparation. Open Chrome's downloads list or your device's Files/Downloads app to verify the result. The destination depends on browser and Android settings, not on the original Instagram post.

Why a large carousel may not fit in one ZIP

Building the archive consumes device memory because the browser has to fetch each item, calculate the archive entries, and assemble the final file. SaveDownloader currently limits browser ZIP preparation to roughly 64 MB total, with a 32 MB limit per item. Those are practical browser safeguards, not Instagram size limits or a promise that every smaller ZIP succeeds on every phone.

If a large video exceeds the ZIP limit, select its individual download button. Individual media has a separate browser-handling threshold. Depending on size and device, a large download may be handed off to the browser instead of processed in memory.

Common ZIP problems

The ZIP button is missing

The combined download option is shown for a result with at least two available media items. Confirm that the original post contains multiple supported items and that the resolver returned them. A single Reel or photo does not need a ZIP.

Preparation stops on a particular item

A source media address can expire or become unavailable while the page is open. Reopen the original public post, resolve it again, and retry. If the same item consistently fails, download available items individually. A successful preview does not guarantee the original media server will deliver the full file.

Safari says the file is ready but I cannot find it

Use the separate Save file link on iPhone, then inspect Safari Downloads and Files. Do not assume the file was saved simply because preparation succeeded. Check free device storage before retrying large archives.

The archive is too large

Download individual items instead of repeatedly creating the same ZIP. This avoids holding an entire multi-video archive in your browser's memory.

When an official export is preferable

For your own posts or a creator's archive, first check the platform's authorized export or download controls. If you manage media for another person, asking them for the original source files can also avoid lower-quality copies and permission uncertainty.
