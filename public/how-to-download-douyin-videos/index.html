How to download Douyin videos on phone or computer

SaveDownloader provides a browser-based way to save public Douyin (抖音) videos. The basic process is the same on iPhone, Android, Windows, macOS, and other modern devices.

Updated August 28, 2026.

Quick method: copy, paste, download

Copy the public Douyin URL. Open the video in Douyin or your browser and use the share/copy-link option.
Open SaveDownloader. Go to the Douyin Video Downloader and paste the copied URL.
Select Get video. SaveDownloader resolves the public post and returns the available media information.
Select Download video. Your browser downloads the resolved file or handles the final media action according to the device and browser settings.

Downloading a Douyin video on iPhone or iPad

Open the public Douyin link, copy it, and paste it into SaveDownloader in Safari or another modern browser. After the video is resolved, select Download video. iOS and the browser determine where the file appears; depending on your settings, you may see the download in the browser's download manager or the Files app.

If the browser opens the video instead of saving it, use the browser's available save or share controls. Browser behavior can vary across iOS versions and media hosts.

Downloading a Douyin video on Android

Copy the public Douyin URL, open SaveDownloader in Chrome or another modern browser, paste the link, and resolve it. Select Download video when the result appears. Android browsers typically use the device's configured Downloads location, although the exact location can differ by browser and device manufacturer.

Downloading a Douyin video on Windows or Mac

On desktop, copy the public Douyin URL from the address bar or share interface. Paste it into SaveDownloader, select Get video, and then choose Download video. Your browser may save the file automatically to its default Downloads folder or ask you where to save it.

Which Douyin links work?

SaveDownloader is built for public Douyin links that can be resolved through the public web. Common inputs include direct video URLs, compatible short share links, and public URLs that contain a Douyin post identifier such as a modal_id.

Copied share text can also work when it contains a valid Douyin URL. If a pasted block of text contains a link, SaveDownloader attempts to extract the first URL and validate it as a Douyin address.

Why does SaveDownloader need the original post link?

The media URL returned by a platform may be temporary or signed. That means a direct CDN link can stop working later even though the original public post still exists. Keeping the original Douyin link lets you resolve a fresh media URL when needed.

Common problems and fixes

“This public post could not be parsed”

The post may have been removed, made private, limited by region, changed format, or Douyin may have changed its public web response. Confirm that the original post is still publicly accessible and try the original URL again.

The media URL expired

Return to SaveDownloader and submit the original Douyin URL again. A fresh resolution may return a new temporary media URL.

The browser opens the video instead of downloading it

SaveDownloader first attempts to download the media in the browser. Some media hosts or browser policies can block that behavior. If the browser opens the media instead, use the browser's normal save controls where available.

The video is private or requires login

SaveDownloader does not support private, authenticated, paywalled, DRM-protected, or otherwise access-controlled content.

Responsible use

Downloading a technically accessible file does not automatically give you rights to reuse, publish, sell, or redistribute it. Use SaveDownloader only for media you own, created, have permission to save, or otherwise have a lawful basis to download.

Current platform support: SaveDownloader currently supports Douyin only. Other social platforms are not part of the public release.
