Supported Instagram URL formats

SaveDownloader is intended for public Instagram post and Reel URLs. The original permalink is the best input because temporary media links can expire.

  • Reels: URLs such as www.instagram.com/reel/SHORTCODE/.
  • Posts: URLs such as www.instagram.com/p/SHORTCODE/.
  • Legacy video pages: compatible /tv/SHORTCODE/ links when Instagram still exposes the public page.
  • Carousel posts: supported when the public page exposes the individual media items.

How to download an Instagram Reel, photo, or carousel

Copy the original public Instagram post or Reel URL, paste it into the downloader above, select Get media, and then use the download button for the resolved item. For a supported carousel with multiple items, Download all (.zip) packages the resolved media into one ZIP download.

For device-specific steps and troubleshooting, read the Instagram download guide.

Public-only access boundaries

SaveDownloader does not ask for Instagram credentials or private account cookies. Private posts, Stories, Highlights, login-only pages, paywalled content, DRM-protected content, and other access-controlled media are not supported.

Why an Instagram download can fail

Instagram can change its public page structure or decide not to expose a post to logged-out visitors. Media CDN URLs can also expire. If a public post stops resolving, use the original Instagram permalink again. A carousel will not be represented by only its cover image when the individual items are unavailable.

Instagram downloader FAQ

Can it download Instagram Reels?

Yes, when Instagram exposes the public Reel and its video media to logged-out visitors.

Can it download Instagram photos?

Yes. Supported public single-photo posts return an image download.

Can it download carousel posts?

Yes when the public page exposes the carousel media. The gallery shows each available image or video separately.

What does Download all do?

For a supported public carousel with multiple resolved items, SaveDownloader fetches those items and packages them into one ZIP file so the browser only needs to start a single download.

Can it download Stories or private posts?

No. Stories, Highlights, private posts, login-only pages, and other access-controlled content are not supported.

Why can a download stop working later?

Instagram CDN URLs can be temporary. Resolve the original public post again to request fresh media information.
