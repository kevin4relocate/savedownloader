Supported TikTok link formats

The resolver is intended for common public TikTok post URLs, including canonical video links and TikTok-owned short links that redirect to a public post.

  • Video pages: URLs such as www.tiktok.com/@user/video/POST_ID.
  • Photo posts: compatible public TikTok photo-post URLs when public image data is present.
  • Short links: compatible vm.tiktok.com, vt.tiktok.com, and other TikTok-owned HTTPS redirects.
  • Shared text: copied text can work when it contains a valid public TikTok URL.

What SaveDownloader does

SaveDownloader requests the public TikTok page, identifies the public post metadata embedded in that page, and returns the media URL made available there. The service does not ask for your TikTok username, password, or private account cookies.

The browser then attempts to save the resolved media directly from the media host. SaveDownloader is designed as a resolver, not as a permanent server-side library of TikTok videos.

Why a TikTok download can fail

A post can stop resolving if it is removed, made private, region-restricted, requires authentication, or if TikTok changes its public page structure. Temporary media URLs can also expire. When that happens, use the original public TikTok post URL again.

Responsible use

Use SaveDownloader only for public media you own, created, have permission to save, or otherwise have a lawful basis to download. Technical availability does not grant permission to republish, redistribute, or monetize someone else's content.
