Supported Douyin URL formats

The resolver is built for common public Douyin link formats. Support can change when Douyin changes its public web responses, so the original public post URL is always the best input.

  • Direct video pages: URLs containing /video/POST_ID.
  • Short share links: compatible v.douyin.com share URLs that redirect to a public post.
  • Featured/Jingxuan URLs: public URLs containing a modal_id post identifier.
  • Shared text: text copied from Douyin can work when it contains a valid public Douyin URL.

What happens after you paste a link?

SaveDownloader extracts the public post identifier, requests the public web metadata needed to locate the media, and returns a temporary media URL. The website does not ask for your Douyin username or password.

When you press the download button, the browser attempts to save the resolved media directly from the media host. SaveDownloader is designed as a resolver rather than a permanent hosting service for downloaded videos.

Why a Douyin download can fail

Public media endpoints are controlled by Douyin and can change. A link may fail when the post has been deleted, made private, restricted by region, requires authentication, or when a temporary media URL has expired. If a previously working result expires, paste the original Douyin post URL again.

Tip: keep the original Douyin post link. Temporary CDN video links are not intended to be permanent bookmarks.

Privacy and access boundaries

SaveDownloader is intended for public media. It does not provide a login flow and is not designed to bypass private accounts, paywalls, DRM, or other access controls. For details about request processing and hosting logs, see the Privacy Policy.
