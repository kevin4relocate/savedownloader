Supported Douyin URL formats

The resolver is built for common public Douyin link formats. Support can change when Douyin changes its public web responses, so the original public post URL is always the best input.

  • Direct video pages: URLs containing /video/POST_ID.
  • Short share links: compatible v.douyin.com share URLs that redirect to a public post.
  • Featured/Jingxuan URLs: public URLs containing a modal_id post identifier.
  • Shared text: text copied from Douyin can work when it contains a valid public Douyin URL.

What happens after you paste a link?

SaveDownloader extracts the public post identifier and requests public web metadata needed to locate supported media. The website does not ask for your Douyin username or password.

When you press the download button, SaveDownloader first attempts the normal browser download flow and can use its own public-media fallback when a temporary Douyin CDN request is rejected by the browser.

Why a Douyin download can fail

Public media endpoints are controlled by Douyin and can change. A link may fail when the post has been deleted, made private, restricted by region, requires authentication, or when temporary media information has expired. If a previously working result expires, paste the original Douyin post URL again.

Tip: keep the original Douyin post link. Temporary CDN video links are not intended to be permanent bookmarks.

Douyin downloader FAQ

No. The current resolver is designed for public Douyin links and does not ask for account credentials.

Does SaveDownloader store the video?

The service is designed to resolve and deliver supported public media rather than keep a permanent server-side library of downloaded videos.

No. Private, authenticated, paywalled, DRM-protected, and access-controlled content is outside the scope of the service.
