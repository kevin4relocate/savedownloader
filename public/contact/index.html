Use the public project tracker for bug reports, product questions, privacy feedback, or rights-related concerns.

Report a problem

If a public Douyin URL fails to resolve, include the URL format, the error message you saw, and your browser/device type. Do not include passwords, private account information, or confidential URLs.

©

Rights or copyright concern

If you are a rights holder or authorized representative, review the Copyright page before sending a report so the request includes enough information to evaluate it.

Public project contact

SaveDownloader currently uses the project's GitHub issue tracker as its public contact channel. Reports submitted there are public, so do not post sensitive or private information.

Open a public support issue

What to include in a bug report

  • A short description of what you expected to happen.
  • The error text shown by SaveDownloader, if any.
  • The type of public Douyin URL you used.
  • Your browser and device type.
  • Whether the same public post still opens normally on Douyin.
Privacy reminder: never send a Douyin password, login cookie, private post URL, payment information, or other confidential data through the public issue tracker.
