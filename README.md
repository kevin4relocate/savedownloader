# SaveDownloader

SaveDownloader is a lightweight multi-platform media downloader project designed for Cloudflare Workers + Static Assets.

The first supported platform is Douyin. The architecture is intentionally provider-based so TikTok, Instagram, and other public-media sources can be added later without changing the frontend contract.

> Use SaveDownloader only for media you own or have permission to save. Private/authenticated content and DRM bypass are out of scope.
